# One UI Live Colors

Samsung One UIのライブ壁紙向けVector / LSPosedモジュール。開発・実機検証中です。

特定の壁紙アプリのパッケージ名、private設定、描画実装には依存せず、標準の`WallpaperColors`をOne UI Homeの既存文字色処理へ補い、ホーム／ドロワーの文字色、ホームのステータスバー、ページ位置通知、音量パネル、壁紙プレビューを個別に設定できます。設定画面はMaterial 3の標準BottomNavigationViewによる下部ナビゲーション方式。全体スイッチと対象アプリごとのスイッチがあります。

対象：SM-S948Q / Android 16 / Vector 2.2。**Android 17 / One UI 9は再解析まで無効**です。互換性を確認できない構造では該当機能を停止します。他の端末への汎用対応を保証するものではありません。

| 機能 | Vectorの対象スコープ |
|---|---|
| ホーム文字色・ホームのステータスバー・ドロワー・ページ通知 | One UI Home `com.sec.android.app.launcher` |
| 音量パネルのライト／ダーク（任意） | System UI `com.android.systemui` |
| 壁紙とスタイルのライブプレビュー（任意） | 壁紙とスタイル `com.samsung.android.app.dressroom` |

`android` / system_server / Zygote、ライブ壁紙アプリ、設定本体 `com.android.settings` をスコープへ追加する必要はありません。Home Upを使用していても、Home Up自身のプロセスへの追加は不要です。

## 機能と制約

- ホーム文字・ステータスバー：自動／黒／白／標準。ドロワーの自動はOne UI標準を維持。
- 標準色通知・壁紙変更・設定変更を受けて更新。定期ポーリングなし。
- One UI Homeと、動的に読み込まれるHome Upのページ位置を標準Android offsetsで通知。設定内の仮ホームからは通知しない。
- 壁紙プレビューは現在のホーム壁紙Surfaceをミラーする。別の壁紙エンジンを起動しない。
- Material 3、ダークモード、ダイナミックカラー、画面端の余白、アプリアイコン。
- 日本語・英語・簡体字・繁体字・韓国語。初期状態はOS言語に追従。アプリ単独の言語選択も可。
- 対象ごとの実行報告をアイコンとバッジで表示。管理アプリがあるだけで「有効」と判定しない。
- 対象ごとの永続的な起動保護。90秒安定動作しない起動が繰り返されると3回目で機能を停止。
- 起動時にrootを要求。rootがなくても設定画面は利用できる。プロセス再起動と保護解除だけはrootが必要。
- システムパーティション、root実装、ホーム配置、壁紙画像を変更しない。端末再起動を行う機能はない。

自動文字色は**壁紙アプリが提供するヒント**に従います。壁紙アプリが色情報を提供しない場合は標準色がnullになることがあり、モジュールはOne UI標準へ戻ります。画像の実輝度の独自測定や、通知のない画像更新の検出は行いません。

MultiPictureの「画面位置で制御」では、壁紙アプリ側の画面数を実際のホームのページ数と合わせてください。例：Home Upが4ページで壁紙が3ページ設定だと、中間位置の画像になります。

起動保護はVector内部の障害、フック処理前の異常、すべてのブートループを防ぐものではありません。

## ビルド

開発フォルダ：`~/Documents/OneUiLiveColors`。JDK 21とAndroid SDK 36を用意し、Android Studioでプロジェクトを開きます。

```sh
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

出力：`app/build/outputs/apk/debug/app-debug.apk`。依存関係の追加・更新でライセンス一覧に差分があるとビルドを停止します。公開APKは開発用署名です。GitHub Actionsの成果物とは署名鍵が異なるため、配布元を混在させた上書き更新はできません。

## 導入

1. 最新APKをインストールし、Vectorでモジュールを有効にする。
2. 使う機能に対応するスコープだけを選ぶ。
3. アプリを開き、必要なら既存root管理環境の権限要求を許可する。
4. 初回とAPK更新後に対象プロセスを起動し直す。アプリ内にホーム再起動、SystemUI／壁紙とスタイルの再読み込みボタンがある。
5. 対象別の実行報告を確認して設定する。通常の色／スイッチ変更ではプロセス再起動不要。

各アプリのスイッチをオフにしても他の対象や保存値は保持します。完全にフック登録を取り除くにはVectorのスコープから外して対象プロセスを起動し直します。

```sh
adb logcat -s OneUiLiveColors:I '*:S'
```
