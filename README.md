# One UI Home Tweaks

SamsungのOne UI HomeをカスタマイズするAndroidアプリです。ホームとドロワーの文字色、アプリ履歴、ライブ壁紙との連携を調整し、音量パネルの配色とクイックパネルのサイズも変更できます。Vector / LSPosedのモジュールとして動作します。

ホームの各アプリ名と下部のファインダーについて、文字のすぐ周囲に描画されている背景の明暗を調べ、読みやすい黒か白を選べます。同じページ内でも、明るい場所と暗い場所で別々の文字色になります。ステータスバーの色は変更しません。

**現在は開発・実機検証中です。** 対応を確認している環境はGalaxy S26 Ultra（SM-S948Q）、Android 16、Vector 2.2です。通常の未root端末にAPKをインストールするだけでは動作しません。Android 17 / One UI 9はSM-S948Q / BZI9で実験対応しています。Android 16用と17用の互換処理は別に維持しています。

## できること

| 機能 | 設定・動作 |
|---|---|
| ホームのアプリ名・ファインダー | 場所ごとに自動／壁紙全体の色情報による自動／黒／白／One UI標準 |
| アプリ一覧（ドロワー）のアプリ名 | 標準の自動配色を維持、または黒／白を指定 |
| 履歴で最後のアプリの描画を継続 | 標準の縦画面・横画面の履歴で最後のアプリだけをライブ表示する実験的機能。初期OFF。Home UpのタスクチェンジャーON／OFFに対応 |
| 履歴中のフォーカス通知 | 標準／通知する／通知しないを選択する実験的機能。継続描画と併用。ゲームごとのスコープ追加は不要 |
| 履歴画面のホームバーを非表示 | ジェスチャー操作時だけ履歴のバーを隠す。3ボタン操作とOSの常時非表示設定を尊重 |
| DIY Homeのアイコン整列 | DIY Homeを維持し、アプリ・フォルダだけを通常ホームのグリッドへ整列。編集時の移動もセル単位。縦画面のみ、初期OFF |
| ライブ壁紙へのページ通知 | ホームのページ位置を壁紙へ通知。Home Upのフリースタイルにも対応 |
| 「壁紙とスタイル」のプレビュー | 現在ホームに描画されているライブ壁紙を表示 |
| クイックパネル | Android 16風の共通背景へ切り替え。明るさ・音量バーの太さ、ダーク／ライトモードとサウンドモードのボタンサイズを個別に調整。50〜120%、100%で標準サイズ。初期OFF |
| 音量パネル | システム設定に従う／ライト／ダークを選択。Sound Assistantの追加パネルにも対応 |
| ステータスバーの日付 | 表示中の日付を時計の左側へ移動。日付の表示・非表示と書式はOS・QuickStarの設定に従う。初期OFF |

DIY Homeの整列は「ホーム」タブで設定します。Home UpでDIY Homeを有効にした状態で使い、通常ホームのグリッド設定を参照します。ウィジェットとステッカーは自由配置のままです。整列のON/OFF自体では保存済みの配置を書き換えません。「整列した配置を保存」で変更件数・ページ数を確認して保存すると、rootやフックが外れても整列後の位置が残ります。ON中に移動したアプリやフォルダは純正の編集処理で保存されるため、OFFにしても編集は取り消されません。横画面・RTLでは純正の自由配置を使います。

履歴の縦向き固定と独自の回転・遷移補正は0.11.0で削除しました。

履歴の継続描画は「ホーム」タブでオンにします。Android 16 / One UI 8.5のジェスチャー操作が対象で、縦・横どちらもOne UI標準の向きと遷移を使い、到着先のカードに最後のアプリをライブ表示します。遠近変形中のカードは一時的に標準の静止画になり、変形後にライブ表示へ戻ります。保護された画面や非対応の構成では標準動作を使います。アプリ側の動画再生・音声ポリシーは変更しないため、すべての動画アプリの再生を保証するものではありません。

各機能は、全体スイッチと対象アプリごとのスイッチでオン・オフできます。色の選択はその場で反映されます。配置の永続保存は専用ボタンで確認して行います。設定画面はMaterial 3の下部ナビゲーションで「ホーム」「表示」「状態」「設定」に分かれています。適用状況はアイコンとバッジで確認でき、対象アプリの再読み込みもアプリ内から行えます。

日本語・英語・簡体字・繁体字・韓国語に対応し、最初は端末の言語を使います。アプリだけの言語変更、ライト／ダークテーマ、ダイナミックカラーにも対応しています。

## 必要な環境

- 対応するSamsung One UI端末。現時点の実機確認はSM-S948Q / Android 16のみです。
- modern libxposed API 102に対応したXposed環境。実機確認はVector 2.2で行っています。legacy API 82環境では読み込まれません。
- 壁紙関連機能にはライブ壁紙が必要です。アプリ履歴の機能は静止画壁紙でも使えます。特定の壁紙アプリ専用の処理はありません。
- 対象プロセスの再読み込み・起動保護の解除には、既存のroot環境が必要です。

rootの要求はアプリ起動時に表示されます。許可しなくても設定画面は使えますが、アプリ内の再読み込みなどは利用できません。本アプリはroot化やブートローダーの解除を行いません。

旧名はOne UI Live Colorsです。アプリIDと配布鍵を継続しているため、既存の設定とVectorスコープを引き継いで上書き更新できます。

## インストールと設定

1. [Releases](https://github.com/ryuya0124/oneui-live-colors/releases)で配布されているAPKをインストールします。
2. VectorでOne UI Home Tweaksを有効にし、下表から使う機能の対象だけを選びます。
3. アプリを開き、必要に応じて既存のroot管理アプリの権限要求を許可します。
4. 初回導入・APK更新後は、アプリ内のボタンなどで対象アプリを再読み込みします。SystemUIの再読み込みでは一時的に画面が閉じ、ロック画面に戻る場合があります。
5. 「状態」で対象からの応答を確認し、文字色や表示を設定します。通常の色・スイッチの変更に再読み込みは不要です。

| 使う機能 | Vectorで選ぶ対象 |
|---|---|
| ホーム・ドロワーの文字色、ページ通知、DIY Homeの整列、履歴の継続描画・ホームバー非表示 | One UI Home（`com.sec.android.app.launcher`） |
| 音量パネル、時計の左側への日付表示 | System UI（`com.android.systemui`） |
| ライブ壁紙のプレビュー | 壁紙とスタイル（`com.samsung.android.app.dressroom`） |

配布済み0.11.0の機能には、ライブ壁紙アプリ、Home Up本体、設定アプリ本体、Androidシステムは追加不要です。Vectorが適用されていない場合は「未確認」と表示され、適用済みとして扱いません。

0.12.0で追加した履歴中のフォーカス通知調整には、追加でAndroidシステム（`system`）を使用します。ゲームごとの追加は不要です。初回読み込みと、システムが起動し直すたびにアプリ内での手動有効化が必要です。通知を受けたアプリが音を止めるかどうかはアプリ側の動作によります。[設計・制約・検証状況](docs/recents-focus.md)を確認してください。

配布APKは専用の署名鍵で署名したreleaseビルドです。初期のdebug版から移行する場合は署名が異なるため、debug版をアンインストールしてからインストールしてください。GitHub Actionsの未署名成果物はそのままインストールできません。

## 使う前に知っておくこと

- **「場所ごとに自動」**は、ライブ壁紙のラベルの背後を個別に調べます。ホームを表示したとき、ページ移動、配置変更、壁紙の色通知で再判定します。壁紙の全体色情報がなくても動作します。画像の取得や座標の対応を確認できなければ標準の色に戻ります。背景画像はメモリ内で処理し、保存・送信しません。初めて表示するアプリ名は、背景の判定後に短くフェード表示します。判定できない場合は標準色へ戻ります。
- 常時ポーリングはしません。壁紙が通知せずに画像を変えた場合は、次のページ移動などまで色が更新されないことがあります。動画の毎フレームやウィジェット・フォルダー内部の背景は対象外です。従来の「自動（壁紙の色情報）」は引き続き壁紙側の通知と色情報が必要です。
- ステータスバーの色指定は廃止しました。別のモジュールやOne UI側に任せます。
- ページごとに画像を設定する壁紙では、壁紙側の画面数と実際のホームのページ数を合わせてください。例えばホーム4ページ・壁紙3ページでは、画像が中間位置になる場合があります。
- プレビューの背景は現在のホームを表示しますが、重ねて表示されるアイコンの配置はSamsung標準のプレビューに従います。
- 履歴の継続描画・ホームバー非表示は「ホーム」タブで個別にオンにします。画面の向きと遷移にはSamsung標準の処理を使います。マルチウィンドウ・外部画面は対象外です。ホームバー非表示はジェスチャー操作時だけ適用し、3ボタンの操作ボタンを隠しません。OSの常時非表示設定は書き換えません。
- ロック画面の文字色は変更しません。壁紙画像とシステムパーティションは変更しません。ホーム配置の保存は「整列した配置を保存」で確認した場合に行います。
- アプリやOSの更新で互換性を確認できなくなった場合は、該当機能を停止します。将来の更新への対応を保証するものではありません。

## 停止・問題が起きたとき

まず全体スイッチ、または対象アプリのスイッチをオフにしてください。完全に適用を外す場合はVectorでモジュールを無効にし、対象アプリを再読み込みします。

不安定な起動が繰り返された場合に、対象ごとにフックを停止する起動保護があります。原因を解消してから、設定内の「クラッシュ保護を解除」で解除できます。Vector内部の障害や、すべてのブートループを防げる機能ではありません。

改善要望・不具合は[Issues](https://github.com/ryuya0124/oneui-live-colors/issues)へ。端末名、Android／One UIのバージョン、対象アプリのバージョン、再現手順を添えてください。個人情報を含むログや壁紙画像をそのまま公開しないでください。

クイックパネルの調整は「表示 → クイックパネル」にあります。プレビュー付きの別画面で4項目を設定し、パネルを開き直すと反映されます。本体の明るさ・音量は変更しません。OFFまたは標準サイズへのリセットで純正の寸法へ戻せます。初回更新時はSystemUIの再読み込みが必要です。
