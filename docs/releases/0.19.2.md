Android 17のクイックパネルをAndroid 16風のデザインで使用しているとき、表示や再描画のタイミングでSystemUIが終了する場合がある問題を修正しました。ダークモード・サウンドモードのボタンの拡縮後も、純正の描画処理を維持します。

対応するGalaxy S26 Ultra（SM-S948Q）のAndroid 16 / One UI 8.5、Android 17 / One UI 9と、root・libxposed API 102対応Vectorが必要です。今回の修正はAndroid 17向けで、Android 16の既存処理は維持しています。

署名済みrelease APKを上書きし、Galaxy ReloadなどでSystemUIのみを読み込み直してください。ソフトリブートは不要で、保存済みの設定は引き継ぎます。Vector本体や別のモジュールが出す接続警告・互換性エラーは、この更新の修正対象に含まれません。
