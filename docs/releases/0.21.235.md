## 変更点

- ホームからアプリを開くときや、ジェスチャーでホームへ戻るときの引っかかりを軽減しました。表示済みの画面を再利用し、アプリの描画が遅いときもアニメーションを先に進めます。純正のアニメーションと温度保護を維持します。
- アプリを開いている間に同じ画面の状態を何度も送り直す処理を減らしました。
- Home UpのDIYホームでページを表示する準備と、設定アプリの一部の読み込みを軽量化しました。

新しい開閉の最適化は、Galaxy S26 Ultra（SM-S948Q）のAndroid 17 / One UI 9（BZI9）で検証したプレリリースです。ゲームで発熱しているときや端末に高い負荷がかかっているときは、フレーム落ちが残ることがあります。

同じ署名のAPKを上書きすると設定を引き継げます。Vectorでホット更新が完了した場合はそのまま使えます。自動反映されない場合はOne UIホームを読み込み直してください。

## What's new

- Reduced stutter when opening apps from Home and returning to Home with a gesture. The transition can reuse an existing frame and continue while the app prepares new content. Samsung's animation and thermal safeguards remain in use.
- Removed repeated updates to surfaces that already had the correct state during app launch.
- Reduced work when preparing DIY Home pages and loading some parts of Samsung Settings.

This pre-release validates the new transition optimizations on the Galaxy S26 Ultra (SM-S948Q) with Android 17 / One UI 9 (BZI9). Some frames can still be missed under heavy load or thermal throttling.

Install over the existing app to keep your settings. If Vector applies the hot update, you can keep using Home. Reload One UI Home if the update has not been applied automatically.
