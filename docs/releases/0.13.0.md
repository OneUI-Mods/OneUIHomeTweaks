# One UI Home Tweaks 0.13.0

クイックパネルの明るさ・音量バーの太さと、ダーク／ライトモード・サウンドモードのボタンサイズを個別に調整できるようになりました。「表示 → クイックパネル」でプレビューを見ながら50〜120%で設定できます。100%が標準です。変更はパネルを開き直すと反映され、OFFやリセットで標準サイズへ戻せます。

クラッシュ保護では、正常な再読み込みや原因不明の終了を連続クラッシュとして数えず、確認できた連続した異常終了3回で停止するよう判定を整理しました。停止中であることもクイックパネル設定画面で確認できます。既に停止している場合は「設定」から保護を解除して再読み込みしてください。

rootとAPI 102対応Vectorが必要です。Android 16の既存機能を維持し、Android 17 / One UI 9はGalaxy S26 Ultra（SM-S948Q / BZI9）で実験対応しています。今回のサイズ機能はAndroid 17で動作を確認しており、Android 16側は実機で未確認です。大きくしたボタンが隣接項目へ近づく場合はサイズを下げてください。

署名済みrelease APKを上書きし、設定画面を開いてからSystemUIを一度再読み込みしてください。その後のサイズ変更に再起動は不要です。本体の明るさ・音量は変更しません。
