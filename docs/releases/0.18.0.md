# One UI Home Tweaks 0.18.0

開発者向けオプションの3種類のアニメーション倍率を、0.01刻みで設定できるようになりました。ウィンドウ・トランジション・Animatorの各項目で、数値入力、±0.01のボタン、スライダーを使えます。

「保存」で反映し、キャンセルや戻る操作では変更しません。「標準値」は入力欄を1.00倍に戻します。一覧にも実際の倍率を表示します。機能をOFFにすると、保存済みの倍率を保ったまま標準の選択画面へ戻ります。

この追加機能はGalaxy S26 Ultra（SM-S948Q）のAndroid 17 / One UI 9 BZI9向けです。Android 16用の既存機能は維持しますが、今回の倍率入力UIはAndroid 16ではまだ使えません。rootとAPI 102対応Vectorが必要です。

署名済みrelease APKで更新後、Vectorの対象に「設定」を追加し、設定アプリを開き直してください。本アプリの「表示」タブで「開発者向けアニメーション倍率」をONにします。これまでの設定値は引き継ぎます。この機能の反映に、端末本体・SystemUI・One UIホームの再起動は不要です。

入力範囲は0.00〜10.00倍です。小さいほど速く、0でアニメーションを無効にします。開発者向けオプション全体をOFFにしたときの倍率リセットは、OS標準の動作に従います。
