# One UI Home Tweaks 0.14.0

クイックパネルに「Android 16のデザイン」を追加しました。明るさ・音量バーと、その下のダーク／ライトモード・サウンドモードのボタンを、ひとつの背景にまとめた見た目へ切り替えられます。対象はこの4か所です。

「表示 → クイックパネル」から切り替え、パネルを開き直すと反映されます。4項目のサイズ調整と併用でき、100%は選んだデザインの標準サイズです。新旧デザインを切り替えてもサイズ設定を保持します。編集には標準の画面を使います。

バーのすぐ下または右に対応するボタンがある配置で適用します。離れた配置や大きすぎる組み合わせでは標準表示になります。新しい切り替えはAndroid 17 / One UI 9のGalaxy S26 Ultra（SM-S948Q / BZI9）向けの実験的機能です。Android 16向けの既存処理は維持しています。

rootとAPI 102対応Vectorが必要です。署名済みrelease APKを上書きし、SystemUIを一度再読み込みしてください。その後のデザイン・サイズ変更は、パネルを開き直すだけで反映されます。
