# One UI Home Tweaks 0.20.7

起動後の初回ロック解除前に設定・DexKitキャッシュへアクセスし、音量キーのパネルなどの初期化が失敗したまま残る経路を修正しました。ホームだけでなく、時計・音量・クイックパネル・設定・壁紙プレビューも、初回解除後に一度だけ初期化します。通常の再ロックでは従来の動作を維持します。

解除通知の重複と、待受登録の途中で解除される競合に対応し、定期ポーリングは行いません。フォーカス連携の受け口も初回解除前の要求を受理しません。

実機では更新前のSystemUIに音量設定スレッドがなく、記録が以前のPIDを指していることを確認しました。SystemUIだけの再読み込みで、純正音量パネル・Sound Assistantのダーク配色フックが復帰しました。元の起動時例外はログが残っておらず断定していませんが、コード上にある初回解除前の依存先アクセスを防止します。

Android 16・17のアダプターと設定値を維持しています。ソフトリブートは行いません。起動順序・解除通知の競合はJVMテストで確認し、実機で冷間起動そのものを再現するための再起動・認証状態変更は行っていません。

Startup initialization now waits for the first user unlock across all app hosts. Duplicate unlock notifications and unlock during listener registration are handled once, without polling. Normal subsequent screen locking does not disable the features. This prevents startup failure paths caused by unavailable CE settings and DexKit caches. Cold-boot behavior has not been re-tested by rebooting the user's device.
