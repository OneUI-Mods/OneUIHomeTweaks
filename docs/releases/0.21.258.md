## 変更点

- Vectorでホット更新を繰り返したときに、古い版のモジュールがメモリに残り続ける問題を修正しました。One UIホームが標準の画面処理に渡していた一部の処理を、更新時に元へ戻します。
- 更新を受け付けないプロセス（スクリーンショットなど）では、新しい版を読み込まずに更新を見送るようにしました。この変更は、各プロセスの次回起動以降に有効になります。

Galaxy S26 Ultra（SM-S948Q）のAndroid 17 / One UI 9（BZI9）で検証したプレリリースです。これまでに溜まったメモリは、One UIホームやシステムUIの再起動、または端末の再起動で解放されます。

同じ署名のAPKを上書きすると設定を引き継げます。Vectorでホット更新が完了した場合はそのまま使えます。自動反映されない場合はOne UIホームを読み込み直してください。

## What's new

- Fixed older module versions staying in memory after repeated hot updates in Vector. Callbacks given to One UI Home are now handed back when an update replaces them.
- Processes that never accept an update, such as screenshots, now skip loading the new version. This takes effect after each process next starts.

This pre-release was validated on the Galaxy S26 Ultra (SM-S948Q) with Android 17 / One UI 9 (BZI9). Memory already used by earlier updates is released after One UI Home or System UI restarts, or after a device restart.

Install over the existing app to keep your settings. If Vector applies the hot update, you can keep using Home. Reload One UI Home if the update has not been applied automatically.
