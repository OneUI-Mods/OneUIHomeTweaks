## 変更点

- Samsungの壁紙・テーマアプリ（Dressroom）が、画面を閉じた後もメモリを抱えたまま残らないようにしました。画面を閉じて30秒たち、Androidがそのアプリをキャッシュ状態と判断した場合だけ、プロセスを終了してメモリを解放します。サービスやジョブが動いている間は終了せず、2分後と10分後にもう一度だけ確認します。次に開いたときは通常どおり起動します。

Galaxy S26 Ultra（SM-S948Q）のAndroid 17 / One UI 9（BZI9）で検証したプレリリースです。実機では、閉じた後に約320 MBを保持していたDressroomが、ホームへ戻ってから約37秒で解放されました。

同じ署名のAPKを上書きすると設定を引き継げます。

## What's new

- Samsung's wallpaper and theme app (Dressroom) no longer stays in memory after its screens close. Thirty seconds after its last screen closes, and only when Android ranks the app as cached, its process ends and the memory returns to the system. It is left running while a service or job keeps it busy, and is checked again only after two and ten minutes. It starts normally the next time it is opened.

This pre-release was validated on the Galaxy S26 Ultra (SM-S948Q) with Android 17 / One UI 9 (BZI9). On the device, Dressroom, which had kept about 320 MB after closing, was released about 37 seconds after returning Home.

Install the APK over the one signed with the same key to keep your settings.
