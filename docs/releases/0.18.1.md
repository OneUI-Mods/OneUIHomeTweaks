DIY Homeのアイコン整列中に、アイコンやフォルダだけが画面上部へ重なったり、右端の外へ移動したりする問題を改善しました。

整列用の寸法が現在のホームと一致しない間は、純正の保存位置を表示します。整列の設定はONのまま保持し、配置データを自動で書き換えません。ウィジェットは従来の位置を維持します。

対応するGalaxy S26 Ultra（SM-S948Q）のAndroid 16 / One UI 8.5、Android 17 / One UI 9と、root・libxposed API 102対応Vectorが必要です。署名済みrelease APKを上書きし、One UI Homeを読み込み直してください。設定は引き継がれます。

画面の向きの変化に伴う一例を確認していますが、すべての発生条件は特定できていません。寸法を取得できない間は、整列した位置とは異なる保存位置が表示される場合があります。
