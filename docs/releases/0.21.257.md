## 変更点

- 高負荷のゲームなどからジェスチャーでホームへ戻るときの引っかかりを大きく減らしました。指を離した直後から、ホームの準備を待たずにアプリ画面が縮むアニメーションを進めます。アイコンはホーム画面が表示できた時点で合流します。
- ホームへ戻るとき、大きな画像のウィジェット（KWGTなど）の転送を前もって始めるようにしました。
- 時計・カレンダーの動くアイコンの読み込みが、ホームの表示を待たせないようにしました（Home UpのDIYホームを含む）。
- 「ホーム画面をメモリに保持」「アプリ履歴をメモリに保持」のスイッチを追加しました。Androidが非表示の画面をメモリから外すときも、選んだ画面を保持します。メモリ使用量が増える場合があります。初期設定はOFFです。

Galaxy S26 Ultra（SM-S948Q）のAndroid 17 / One UI 9（BZI9）で検証したプレリリースです。ゲームで発熱している状態での計測では、ホームへ戻るアニメーション中の表示の途切れが、従来の約0.24〜0.79秒から0.16秒以下になりました。アニメーションの見た目の動きは純正より早く終わることがあり、戻る途中で別のアプリを開いた場合は、純正のアニメーションに切り替わる際に位置が少し戻って見えることがあります。

同じ署名のAPKを上書きすると設定を引き継げます。Vectorでホット更新が完了した場合はそのまま使えます。自動反映されない場合はOne UIホームを読み込み直してください。

## What's new

- Greatly reduced stutter when returning to Home with a gesture from demanding games. The app window starts shrinking as soon as you lift your finger, without waiting for Home to get ready. The app icon joins as soon as Home can be shown.
- Large picture-based widgets (such as KWGT) start uploading their images earlier when you return to Home.
- Loading animated clock and calendar icons no longer holds up Home, including DIY Home in Home Up.
- Added switches to keep Home and Recents in memory. They keep the selected screens ready when Android reclaims stopped screens. This can increase memory use. Both are off by default.

This pre-release was validated on the Galaxy S26 Ultra (SM-S948Q) with Android 17 / One UI 9 (BZI9). In tests with a hot, demanding game, dropped display time during the return-to-Home animation fell from about 0.24–0.79 s to 0.16 s or less. The motion can finish slightly earlier than Samsung's animation. If you open another app while returning to Home, the window can step back slightly when Samsung's animation takes over.

Install over the existing app to keep your settings. If Vector applies the hot update, you can keep using Home. Reload One UI Home if the update has not been applied automatically.
