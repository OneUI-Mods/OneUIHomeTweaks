## 変更点

- 最近使ったアプリの画面（タスクのスナップショット）をメモリに保持する枚数を、アプリの設定から変えられるようにしました。初期値はAndroid標準の5枚です。範囲は2〜20枚で、20はSamsungの標準値です。1枚あたり約18 MBのグラフィックスメモリを使うため、枚数を減らすと端末のメモリに余裕が生まれます。保持から外れた画面は、保存済みの低解像度版から読み込み直します。
- 設定は「ホームを使用しているときの」設定カードのスライダーです。変更は、次にアプリの画面が記録されたときに反映されます。

Galaxy S26 Ultra（SM-S948Q）のAndroid 17 / One UI 9（BZI9）で検証したプレリリースです。実機では、system_serverのグラフィックスメモリが約175 MBから約103 MBへ減りました。

同じ署名のAPKを上書きすると設定を引き継げます。Vectorでホット更新が完了した場合は、保持枚数は一度標準値に戻り、One UIホームの再起動またはスライダー操作で設定値に同期されます。

## What's new

- The number of recent-app screenshots (task snapshots) kept in memory can now be changed in the app. The default is Android's five. The range is 2 to 20, where 20 is Samsung's stock value. Each screenshot uses about 18 MB of graphics memory, so fewer screenshots leave more memory free. Screenshots that are dropped reload from the stored low-resolution copy.
- The slider is in the Home settings card. A change applies the next time the system records an app screenshot.

This pre-release was validated on the Galaxy S26 Ultra (SM-S948Q) with Android 17 / One UI 9 (BZI9). On the device, system_server graphics memory dropped from about 175 MB to about 103 MB.

Install the APK over the one signed with the same key to keep your settings. After a completed Vector hot update the count returns to the default until One UI Home restarts or the slider is moved.
