# One UI Home Tweaks 0.17.0

アプリの識別名とパッケージ名をOne UI Home Tweaksに統一し、OneUI Modsへ移管しました。既存のAndroid 16・17向け機能は維持しています。

パッケージ名が変わるため、旧版とは別のアプリとしてインストールされます。旧版を削除する前に設定を引き継いでください。設定を確認した後、Vectorで旧版を無効にし、新版を有効にして同じ対象アプリを選択し、対象プロセスを再読み込みしてください。システム内に常駐する処理も新しい識別名へ切り替えるため、移行を確認した後に一度システムを起動し直してください。互換用アプリや旧パッケージの別名は残しません。

この版の公開先は[OneUI Mods / OneUIHomeTweaks](https://github.com/OneUI-Mods/OneUIHomeTweaks)です。以前のリポジトリとリリースへのリンクはGitHubの転送先として残ります。
