# One UI Home Tweaks 0.20.8

DIY Homeのアイコン整列が、画面サイズの不一致で止まったままになる場合を改善しました。不一致を検出した場合は、通常ホーム用の寸法を純正の仕組みから取り直し、実際の表示領域に収まることを確認して整列を再開します。

保存済みの配置やウィジェットは変更しません。整列をOFFにした場合の純正動作も維持します。Android 16の既存経路を保ち、今回の補正はAndroid 17に適用します。

署名済みAPKを上書きし、One UIホームを読み込み直してください。端末全体やSystemUIの再起動は不要です。

DIY Home icon alignment can now recover when native grid dimensions no longer match the measured home page. The module retries using Samsung’s home-context geometry and resumes only if it fits the actual page. Saved positions, widgets, and the off setting are preserved. Android 16 keeps its existing path; this recovery targets Android 17. Install the signed update and reload One UI Home; no device or SystemUI restart is required.
