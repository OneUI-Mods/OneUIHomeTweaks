## 変更点

- ホームに戻るたびに設定を読み直す処理を省き、ホーム復帰時の負荷を減らしました。壁紙に合わせたラベル色はホームに戻ったときも更新します。
- 「ホーム画面をメモリに保持」と「ホームを離れたとき描画キャッシュを回収」を「ホーム」タブで近くに配置し、個別に切り替えて併用できることを明記しました。

対応するAndroid 17のGalaxyでは、既存版へ上書きすると設定を引き継げます。

## Changes

- Returning to Home now does less work by skipping redundant reads of module settings. Label colors still adapt to the wallpaper when you return.
- The Home tab places Keep Home in memory next to the drawing-cache option and explains that you can use both. Each setting has its own switch.

An in-place update preserves settings on supported Galaxy devices running Android 17.
