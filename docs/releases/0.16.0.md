# One UI Home Tweaks 0.16.0

フォルダ内のアイコンから起動したアプリをホームジェスチャーで閉じる際、フォルダ内へ戻るか、フォルダを閉じたホームへ戻るかを選べるようになりました。「ホーム」タブの「アプリを閉じたらフォルダ内へ戻る」で変更できます。初期状態はONです。

フォルダへ戻った後の閉じアニメーションを見直し、現在の位置と縮尺に合わせて純正の動きを描画します。

クイックパネルのバーの太さ・ボタンサイズを25〜200%で調整でき、Android 16デザイン向けのサイズプリセットを追加しました。設定画面のプレビューは純正パーツを埋め込み、パネルを開かずに確認できます。通常デザインでのプレビュー表示は検証中で、表示できない場合もサイズの設定は使用できます。

Android 17 / One UI 9のGalaxy S26 Ultra（SM-S948Q / BZI9）向けの実験的な更新です。Android 16の既存処理は別定義で維持しています。rootとAPI 102対応Vectorが必要です。署名済みrelease APKを上書きし、One UIホームを一度再読み込みしてください。クイックパネルのプレビュー更新にはSystemUIの再読み込みも必要です。フォルダの設定変更に再読み込みは不要です。
