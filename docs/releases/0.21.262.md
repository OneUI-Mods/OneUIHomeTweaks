## 変更点

- ホームのラベル位置と色が変わらないとき、レイアウト通知による壁紙の撮り直しを省きます。ホームに戻ったときや、壁紙やページが変わったときはラベル色を再判定します。

対応するAndroid 17のGalaxyでは、既存版へ上書きすると設定を引き継げます。

## Changes

- Home label colors reuse their wallpaper samples when a layout notification leaves the labels in the same positions with the same colors. The module checks contrast again when you return home or change the wallpaper or page.

An in-place update preserves settings on supported Galaxy devices running Android 17.
