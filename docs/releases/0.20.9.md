# One UI Home Tweaks 0.20.9

DIY Homeのページが表示されて寸法が確定した際に、アイコングリッドを再適用するようにしました。ロック中など、ページが未測定のまま初期化された後に、整列が待機したままになる問題を改善します。

ページのサイズ変更通知でのみ再試行し、定期監視は行いません。実測領域との照合、保存配置・ウィジェットの保護、Android 16の既存処理を維持します。未測定の待機を、寸法の不一致と区別して表示します。

署名済みAPKを上書きし、One UIホームを読み込み直してください。端末全体やSystemUIの再起動は不要です。

DIY Home icon alignment is reapplied when a page receives its measured bounds. This addresses startup while a page is still unmeasured, such as behind the lock screen. Recovery runs on page-size notifications and adds no polling. Viewport checks, saved positions, widgets, and the existing Android 16 path are preserved. Unmeasured pages are no longer reported as having mismatched dimensions. Install the signed update and reload One UI Home; no device or SystemUI restart is required.
