# One UI Home Tweaks 0.15.0

クイックパネルの明るさ・音量バーの太さと、ダーク／ライトモード・サウンドモードのボタンサイズを、25〜200%で調整できるようになりました。5%刻みの操作と保存済みの設定は維持します。

Android 16デザインには「バー110%・ボタン105%にする」ボタンを追加しました。4項目をまとめて設定した後も、それぞれ調整できます。100%は引き続き選んだデザインの標準サイズです。

手描きのプレビューを、SystemUIの純正パーツと現在の状態を使う埋め込み表示へ変更しました。クイックパネルを開かずに設定画面内で確認でき、プレビューを触っても本体の明るさや音量は変わりません。表示を閉じると描画と状態の監視を停止します。

「表示 → クイックパネル」から設定できます。大きいサイズは周囲と重なったり、純正の表示枠で切れる場合があります。Android 16デザインは対応ボタンがバーのすぐ下・右にある配置で適用します。

Android 17 / One UI 9のGalaxy S26 Ultra（SM-S948Q / BZI9）向けの実験的機能です。Android 16向けの既存処理も維持しています。rootとAPI 102対応Vectorが必要です。署名済みrelease APKを上書きし、SystemUIを一度再読み込みしてください。その後のサイズ変更はパネルを開き直すだけで反映されます。
