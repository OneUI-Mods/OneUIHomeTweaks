## 変更点

- 「ホーム」タブに「ホームを離れたとき描画キャッシュを回収」を追加しました。オンにすると、ホームが12秒間非表示のとき、未使用の描画キャッシュを回収します。初期設定はオフで、切り替えに再起動は不要です。

対応するAndroid 17のGalaxyでは、既存版へ上書きすると設定を引き継げます。

## Changes

- The Home tab has a new setting to free unused drawing cache after Home has been hidden for 12 seconds. It is off by default and can be toggled without restarting.

An in-place update preserves settings on supported Galaxy devices running Android 17.
