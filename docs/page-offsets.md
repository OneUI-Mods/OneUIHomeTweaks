# ページ移動とライブ壁紙

## 書込元の競合

ホーム側がページ0/1とstep 1/3を送っている一方、ライブ壁紙Engineの最終値がx=0.5・step=-1になっている状態を実機で取得した。ページ座標の計算成功だけでは、最終的な壁紙入力の確認にはならない。

通常のメインホームに限って、同じwindow tokenへの`WallpaperManager.setWallpaperOffsets`で最新の検証済みworkspace座標を用いる。呼出元のWallpaperManagerインスタンス自身のstepを設定するため、別インスタンスの既定値(-1)による上書きも避ける。自身の書込・別token・リモートプレビュー・DeX・非表示・フォーカスなし・フォルダなど通常ホーム以外の状態・無効時は介入しない。常駐やポーリングは増やさない。例外時にはこの補正のみを止め、純正の書込を維持する。
