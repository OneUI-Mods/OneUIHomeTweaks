# パッケージ名の移行

旧: `net.ryuya_dev.oneuilivecolors`、新: `dev.ryuya.oneuihometweaks`。配布署名鍵は継続する。

実機の移行では、旧版を停止して設定XMLを非公開のroot専用ディレクトリに保全し、新版をインストールしてから`modes.xml`、`app_ui.xml`、`grid_save.xml`をコピーする。所有UID・アクセス権・SELinuxラベルを新版へ合わせる。ホストの診断状態・キャッシュ・プロファイルは移さない。

新旧の設定内容が一致すること、新版から設定を読めること、Vectorのスコープが維持されることを確認する。旧版の無効化と新版の有効化を済ませてから対象プロセスを再読み込みする。移行が完了するまで旧版はアンインストールしない。認証設定は変更しない。system_serverに常駐するモジュールは最後の起動し直しで新版へ切り替える。

Android 16・17の契約は変更せず、パッケージ名とprovider authority・アプリ側の参照のみを更新する。

## 移行操作

配布APKと同じ証明書で署名された旧版を照合し、root経由で設定を保全・コピーする補助スクリプトです。

```sh
python3 tools/migrate_package.py --serial DEVICE_SERIAL --apk OneUIHomeTweaks-0.17.0-release.apk
```

複数のADBサーバーを使う場合は`--adb-port`を指定します。この処理は新旧APKの署名・パッケージ名・release設定を検証し、設定3ファイルをroot専用の端末内ディレクトリへバックアップします。コピー後に内容が一致することを確認します。認証やロック設定は変更しません。

新版の設定を確認してからVectorの新モジュールを有効にし、旧モジュールを無効にして旧アプリを削除してください。旧版の互換アプリ・provider・パッケージ別名は残しません。system_server内の履歴制御も新しい識別名へ移るため、最後にシステムを起動し直して読み込みます。スクリプトが勝手に再起動することはありません。
